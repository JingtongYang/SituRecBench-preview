Action Space and Runtime Execution

Shared / Actions

API-style reference for the closed-loop episode runtime. The central step is step(player_name, action): it records a dialogue action, applies valid customer tool calls to the simulator, updates observations, and returns the next TimeStep.

class SitRecEpisode(chatarena.environments.base.Environment)

The episode environment wraps the assistant, simulated customer, simulator state, observations, turn records, terminal logic, and saved artifacts. It follows the same documentation shape as an environment API reference, while retaining the actual SituRec runtime return type and logs.

Parameters

SitRecEpisode.step(player_name: str, action: str) -> TimeStepRuns one timestep using a serialized assistant or customer action. For user turns, this applies exactly one validated customer tool call and updates the simulator state.

SitRecEpisode.step(player_name: str, action: str) -> TimeStep

Runs one timestep using a serialized assistant or customer action. For user turns, this applies exactly one validated customer tool call and updates the simulator state.

Parameters

  • player_name: assistant or user.
  • action: JSON string with type, content, and tool_calls. Assistant payloads also include exactly one assistant_actions object, one expected_user_action object, and recommendation_ranking for logging and evaluation.

Returns

  • observation: next visible messages, or all messages if the episode has terminated.
  • reward: zero rewards from get_zero_rewards().
  • terminal: whether the episode has reached a terminal condition.

Notes

  • Assistant tool_calls must be empty; assistant_actions are structured records, not executable simulator tools.
  • User tool_calls are executed by apply_tool_calls_from_action(), Customer methods, and EnvWrapper methods.
  • Metrics and debug information are saved in event JSONL files rather than returned as a separate info dict.
SitRecEpisode.is_terminal() -> boolComputes whether the episode should stop and stores the terminal_reason.

SitRecEpisode.is_terminal() -> bool

Computes whether the episode should stop and stores the terminal_reason.

Returns

  • True when the cart, turn limit, or recommendation-attempt logic ends the episode; otherwise False.

Notes

SitRecEpisode.close() -> NoneCloses the run log and restores stdout/stderr when the episode finishes.

SitRecEpisode.close() -> None

State Attributes

  • action_space - Scene-specific customer tool set. Supermarket enables fixture movement and pickup/drop; furniture enables store/area movement and check/reject.
  • assistant_action_space - Structured assistant_actions types: Greet, AskPreference, ClarifyNeed, Navigate, Recommend, Explain, AnswerQuestion, Compare, HandleRejection, ConfirmPurchase.
  • observation - First-person RGB, depth visualization, raw object mask, role-specific overlay/map data, plus visible item and location handles.
  • turn_records - In-memory per-step record expanded after the episode into assistant, navigation, recommendation, camera, dialogue, and terminal artifacts.
  • terminal_reason - Current stop reason, such as cart success, max turn, or recommendation exhaustion.

Customer.move_backward(duration) -> boolMoves the customer actor backward for the requested duration while preserving the final facing direction.

Customer.move_backward(duration) -> bool

Moves the customer actor backward for the requested duration while preserving the final facing direction.

Parameters

  • duration: positive number.

Returns

  • True after the simulator command completes.

Notes

  • Allowed in supermarket and furniture scenes.
  • Implementation: Customer.move_backward() calls EnvWrapper.move_backward(actor_name, duration), then refreshes actor and camera pose.
  • EnvWrapper.move_backward() saves the actor's current UE rotation, temporarily turns 180 degrees, performs _remote_move(actor_name, forward, duration), then restores the saved rotation with set_object_rotation.
  • Short-distance movement uses StartRemoteMove forward only; lateral and backward movement are expressed through temporary rotations plus forward movement.

Customer.side_step(direction, duration) -> boolMoves laterally left or right while preserving the customer's facing direction.

Customer.side_step(direction, duration) -> bool

Moves laterally left or right while preserving the customer's facing direction.

Parameters

  • direction: left or right.
  • duration: positive number.

Returns

  • True after the simulator side-step completes.

Notes

  • Allowed in supermarket and furniture scenes.
  • Implementation: Customer.side_step() calls EnvWrapper.side_step(actor_name, direction, duration), then refreshes actor and camera pose.
  • EnvWrapper.side_step() validates direction, saves the actor's current UE rotation, temporarily turns 90 degrees toward that side, performs _remote_move(actor_name, forward, duration), then restores the saved rotation with set_object_rotation.
  • Short-distance movement uses StartRemoteMove forward only; lateral and backward movement are expressed through temporary rotations plus forward movement.
  • The result is a lateral move for inspecting nearby shelves, fixtures, stores, or furniture displays without turning the body toward that side.
