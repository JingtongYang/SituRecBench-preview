# SituRecBench project website

Static website for **SituRecBench: A Benchmark for Situated Recommendation
in 3D Interactive Environments**.

## Publish on GitHub Pages

1. Create a repository named `SituRecBench` and upload this directory's contents
   to its `main` branch, including `.github/workflows/pages.yml` and `.nojekyll`.
2. Open **Settings → Pages → Build and deployment**, and select **GitHub Actions**.
3. Run **Publish SituRecBench** in Actions, or push an update to `main`.
4. Open the website URL reported by the successful deployment.

This directory is generated by `scripts/build_github_pages.py` in the source
project. Edit the source project and export again for subsequent updates.
The public website displays English content without translation controls
or a translation service. Internal review translations are not published.
